# 俄语考研智能背词系统

包含 React 前端、FastAPI 后端、5505条俄语词汇、2020/2021/2023/2024/2026五份真题及词频索引。
支持每日新学10词分组、FSRS到期复习、独立收藏词本、真题出处、本地词典、DeepSeek词典和在线俄语发音缓存。

## Windows 使用
安装 Python 3.11+（勾选 Add Python to PATH）与 Node.js 24+，下载整个项目并解压，双击 start.bat。
首次联网安装依赖，随后自动打开 http://127.0.0.1:8000 。保持服务窗口运行。
AI功能需在设置页填写自己的DeepSeek API Key。未配置时本地学习不受影响。

## 数据
seed-data 是随项目分发的初始词库及真题。首次启动复制到 data，已有文件不会被覆盖。
个人进度、收藏及缓存只写入 data，该目录不提交Git。backend/.env 存储自己的Key，也不提交Git。
完整备份请先关闭服务器，再复制整个data目录。
初始数据库不含原作者的学习进度、收藏、AI缓存或密钥。

## 限制
本项目是本地单用户开发版，GitHub存储代码和资料，不能仅靠GitHub Pages运行Python后端。
2023、2024真题来自OCR，词频可能有识别误差；歧义词形不计入确认词频。原词表释义按提供文件保留，未逐条人工核实。
资料随项目供学习使用，公开传播前请确认相应授权。

自动安装：start.bat检查Python 3.11+和Node 24+，缺少时通过Windows winget启动下载和安装。
使用者需完成安装条款和Windows确认；安装完成后重新双击start.bat，以便读取新PATH。
没有winget时，提示从微软商店安装“应用安装程序”，或手动下载运行环境。
