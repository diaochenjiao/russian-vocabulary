俄语考研背词系统 · 新版（包含收藏词本）

1. 解压整个压缩包到固定文件夹，不能直接在压缩包中运行。
2. 安装 Python 3.11+，勾选 Add Python to PATH：https://www.python.org/downloads/
3. 安装 Node.js 24+：https://nodejs.org/
4. 双击 start.bat。首次联网安装依赖，成功后自动打开网页。
5. 以后每天双击同一个 start.bat，使用期间保持服务窗口打开。
6. 未自动打开时，用 Edge 或 Chrome 访问 http://127.0.0.1:8000 。

已包含5505条词汇及2020、2021、2023、2024、2026五份真题和索引，无须重新导入。2023和2024为OCR识别，可能有误差。
支持每日新词计划、10词分组、独立到期复习、高频词释义、AI词典及独立收藏词本。
不含发送者密钥、学习记录、个人收藏和AI缓存，你的学习进度独立从零开始。
AI功能：设置与备份中填写你自己的DeepSeek API Key，保存并测试连接。无Key也可使用本地学习和真题查询。
发音首次需要联网，当前单词发送到在线语音服务，成功后缓存在本机。

数据位于data目录，务必保留。完整备份：关闭服务后复制整个data文件夹。
不要用压缩包里的初始data覆盖自己已经学习过的data。
